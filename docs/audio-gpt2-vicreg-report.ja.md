# GPT-2式初期化とVICReg型補助損失：各10k更新の結果

2026年11月2日 JST。GPT-2式の残差出力初期化を先に10,000更新で評価し、その後、同じ初期値から分散・共分散項を加えて10,000更新した。**今回のVICReg型追加は、有効rankを増やしたが、潜在予測と下流probeを悪化させた。** この係数・適用位置は既定値に採用しない。GPT-2式初期化だけの条件は、前回の1e-4方式とMIDI F1がほぼ同等で、全指標での改善はなかった。

[実装・数式・再実行手順](audio-gpt2-vicreg.ja.md)と[匿名化した集計JSON](../experiments/results/audio-gpt2-vicreg-20261102.json)を併記する。

## 比較条件

48 kHz stereoを50 msずつ直接パッチ化し、4800→128投影、幅128・2層の双方向Transformerへ渡す。CNNや時間平均poolingを追加せず、20 FPSを維持した。パッチ投影はrandom初期化のまま。Attention出力投影とFFN末尾だけを正規分布、標準偏差`0.02 / sqrt(2L)`で初期化した。2層では0.01で、全重みをGPT-2と同じ分布に変更したわけではない。

潜在予測は40%・4フレームspanのマスク、EMA教師、Smooth L1を維持する。教師は同じ音声のマスクなし特徴を録音ごと・次元ごとに時間標準化する。追加条件は、別forwardしたマスクなし生徒encoderの出力に分散・共分散ペナルティを掛ける。

`L = L_latent + L_variance + 0.04 * L_covariance`

分散の目標stdは1、epsilonは1e-4。完全かつ有音のパッチだけを使い、音楽1/2・英語1/4・日本語1/4、群内の録音を等重みにする。新たなprojectorは使わない。元のVICRegの完全再現ではなく、EMA潜在予測に対する補助損失である。

どちらもseed `20261102`、batch 8、4秒以下crop、AdamW、LR 3e-4、warmup 50更新。入力順・crop・mask・初期重み・正解を共有し、各条件を最初から学習した。GPT-2単独の学習・評価・監査が済んでから追加条件を開始した。

## 共通の凍結probeによるtest結果

数値は%。有効rankだけは無次元。前回の2条件は既存集計からの参照で、今回の再学習ではない。入力・正解・分割・コードブック・学習スケジュールの一致を照合した。

| 条件 | 更新数 | 音響accuracy | MIDIフレームF1 | MIDI micro AP | 有効rank |
| --- | ---: | ---: | ---: | ---: | ---: |
| 前回：通常初期化 | 10,000 | 33.40 | 15.38 | 11.97 | 24.54 |
| 前回：残差出力を1e-4倍 | 10,000 | 34.13 | 19.26 | 17.27 | 34.40 |
| 今回：GPT-2共通初期値 | 0 | 28.76 | 17.57 | 11.00 | 53.26 |
| GPT-2式＋潜在予測 | 10,000 | 33.31 | 19.25 | 16.25 | 24.49 |
| GPT-2式＋潜在予測＋VICReg型 | 10,000 | 25.21 | 13.87 | 7.84 | 110.35 |

音響accuracyは64音響クラスタに対する音楽1/2・英語1/4・日本語1/4の集計で、クラス均等accuracyではない。音楽・英語・日本語別では、GPT-2単独が51.43 / 9.69 / 20.71%、追加条件が46.16 / 1.12 / 7.39%だった。

MIDIは50 ms中心の128鍵の押下フレーム分類で、音符・onset F1や完成した採譜の評価ではない。GPT-2単独のprecision / recallは12.57 / 41.07%、追加条件は9.92 / 23.01%。旧1e-4方式の18.91 / 19.61%とは検出の傾向も異なる。micro APは同じF1選択済みreadoutから算出し、AP専用の再fitはしない。

validationの音響accuracy / MIDI F1 / APも、GPT-2単独の20.13 / 32.55 / 22.39%に対し、追加条件は12.09 / 22.78 / 14.99%だった。readoutのridge係数・MIDI閾値はvalidationのみで選び、全条件とも最終10k checkpointを評価した。

## 分散は増えたが予測headはほぼ一定になった

以下は固定6録音・420有音フレームのvalidation診断、最終更新時点。上表の全test特徴のrankとは標本集合が異なる。

| 指標 | GPT-2式＋潜在予測 | ＋VICReg型 |
| --- | ---: | ---: |
| masked潜在loss | 0.39282 | 0.42865 |
| ゼロ予測loss | 0.43691 | 0.42848 |
| ゼロ予測比の改善率 | +10.09% | −0.04% |
| predictor出力std | 0.26658 | 0.00239 |
| raw教師の時間std | 0.67247 | 1.05008 |
| 正則化標本の平均std | 0.71581 | 1.05938 |
| 分散ペナルティ | 0.28890 | 0.00148 |
| 共分散ペナルティ | 2.36738 | 0.40662 |
| 生徒の有効rank | 23.05 | 110.04 |
| 同一ドメインの別音声との特徴差RMS | 0.97313 | 1.49727 |

追加条件は分散・共分散の目的を満たす方向へ進んだ。一方、predictorの変動は非常に小さく、マスク位置の予測はゼロ予測を上回らなかった。教師targetの退化フラグは両方0で、encoder自体は入力によって変わる。**encoder全体が定数になったという結果ではなく、潜在予測headがほぼ一定になり、有用な予測を得られなかった結果**と解釈する。

rankやstdの増加だけを成功判定に使うと、この悪化を見逃す。ゼロ予測との差、predictorの変動、共通の下流probeを併用する意義が確認できた。補助項がマスクから予測しやすい情報より分散・無相関化を優先させた可能性はあるが、係数・適用層を分離した実験はしておらず、原因の確定ではない。VICReg一般が不適切という結論にはしない。

## データ・検証範囲・保存

BabySlakh音楽、MiniLibri英語、JSUT日本語を使用。trainは音楽71録音・14曲、英語252録音・27話者群、日本語640発話。validation/testの音楽はそれぞれ3曲ずつで、同一曲のstemを独立曲と数えない。JSUTは同一話者の発話分割で、未知話者への汎化ではない。

probeはtrain/validation/testの412 / 27 / 46窓。音響は32,278 / 1,972 / 3,454フレーム、MIDIは14,400 / 480 / 880フレーム。MIDI利用可能な音源は45 / 6 / 11、除外は26 / 5 / 3だった。1 seed、小規模な音楽test、過去にも参照した探索的評価であり、順位の一般化や統計的有意性は主張しない。環境音、ASRのCER/WER、LLM接続、30〜60秒の長時間採譜は今回の対象外。

学習ループはGPT-2単独454.55秒、追加条件535.24秒で、追加条件は約17.8%長かった。前処理・probe・監査時間は含まない。encoderは1,025,216パラメータで共通。

実装revisionは`70f8ecb434c2f558cf05d9b9a0f8bb16053004de`、実行時dirtyなし。単体検証は191 passed・1 skipped、Ruff成功。GPUスモークは各4更新、実験本番は合計20,000更新。optimizer step、損失成分、同一初期値、共有正解、保存encoder/readoutからの全test予測再現、TensorBoard、24成果物のSHA256監査がすべて通った。各encoderで同じ3,454 testフレームを再現した。既存実験91ファイルの内容もSHA256一致を確認した。

データ・重み・checkpoint・生ログはGit除外の`runs/audio-gpt2-vicreg-20261102/`へ保存した。Gitにはソース・手順・この集計だけを残す。既存TensorBoardのport 6007で`GPT2_VIC/latent/tensorboard`と`GPT2_VIC/latent_vicreg/tensorboard`を比較できる。音声・正解・probe予測画像に加え、`validation/predictor_std`、`validation/relative_gain_over_zero`、`validation/student_effective_rank`、`train/variance`、`train/covariance`を確認できる。
